05 / Limites

Ce que le modèle permet — et ne permet pas

Une aide à l’analyse et à la priorisation, pas une mesure directe de disponibilité.

Points de vigilance

  • Le jeu d’apprentissage comporte 60 mois : la taille d’échantillon limite la robustesse et la généralisation.
  • Les scores sont des performances expérimentales, pas une garantie de détection future.
  • Les sources pollen changent de méthode : RNSA pour 2021–2022 puis CAMS / Copernicus à partir de 2023.
  • Le réseau RNSA a été liquidé en mars 2025 ; aucune nouvelle donnée de stations RNSA n’est disponible pour 2025 selon la documentation du projet.
  • OpenMedic mesure des remboursements en ville, pas les ventes totales ni les stocks réels.

À ne pas interpréter comme

  • Une prévision certaine de rupture ou de date de retour à la normale.
  • Une visibilité sur les stocks des fabricants, répartiteurs ou pharmacies.
  • Une relation causale entre un taxon de pollen et un événement de rupture.
  • Une alerte réglementaire ou une recommandation médicale.
  • Un modèle prêt à être utilisé seul pour décider d’un approvisionnement.
Note de cohérence documentaire : le code du dashboard principal, src/analysis/kpis.py et le dictionnaire de données indiquent une ROC-AUC Random Forest de 0,771 et une baseline logistique de 0,457. Une table de synthèse du README contient d’autres valeurs (0,593 et 0,679) ; ces chiffres doivent être réconciliés avec le protocole d’évaluation avant toute communication externe.
